# QR Cloud Printing System

This project allows users to print documents by scanning a QR code.

Users scan the QR code, upload their files through a webpage, choose print options, and the file is printed automatically on the shop PC.

The system uses FastAPI for the backend and WebSocket to send print jobs to a local print agent.

No user data is permanently stored. Files are temporarily saved and deleted after printing.

This project is built for educational and demonstration purposes.
